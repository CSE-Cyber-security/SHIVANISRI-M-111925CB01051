# Simple Calculator in Python

## 📌 About
This is a simple calculator program developed using Python. It performs basic mathematical operations such as addition, subtraction, multiplication, and division.

## 🛠️ Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero
- Checks for invalid operators

## 💻 Technologies Used
- Python

## ▶️ How to Run
1. Install Python on your computer.
2. Open the terminal or command prompt.
3. Run the program using:

```bash
python calculator.py
```

## 📷 Example

```text
Enter first number: 10
Enter operator (+, -, *, /): *
Enter second number: 5
Result = 50.0
```
